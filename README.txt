
NAOL GANGSTER — GAME PROJECT

Files:
1. index.html
2. style.css
3. world.js
4. car.js
5. game.js

CONTROLS
W / Arrow Up       = Accelerate
S / Arrow Down     = Brake / Reverse
A / Arrow Left     = Turn left
D / Arrow Right    = Turn right
Space              = Brake
C                  = Change camera
E                  = Enter / Exit vehicle mode
P                  = Pause movement
L                  = Headlights

MOBILE
- Drag the steering wheel left or right.
- Hold ACCELERATE to drive.
- Hold BRAKE to slow down or reverse.
- Use camera buttons to change the view.
- Use ENTER / EXIT to switch vehicle mode.

REQUIREMENTS
- Internet connection for the Three.js CDN.
- Upload all five project files to the same GitHub Pages folder.
- Preserve all filenames and letter cases.
